# @shadcn/designer Clone

This project is a clone of the `@shadcn/designer` library, built from scratch with React, TypeScript, and Tailwind CSS.

## Features

*   **Component Composition**: The entire designer is built from small, reusable, and composable components.
*   **Action-Based State Management**: All state modifications occur through dispatched actions, not direct state mutation.
*   **Extensibility**: The system is designed for extension, allowing for custom layer types and actions.
*   **Controlled & Uncontrolled Modes**: The main `<Designer>` component supports both uncontrolled and controlled modes.
*   **Headless Core Logic**: The core state logic is decoupled from the React components.
*   **TypeScript Supremacy**: The entire project is written in TypeScript.

## Getting Started

1.  Install dependencies: `npm install`
2.  Start the development server: `npm run dev`
